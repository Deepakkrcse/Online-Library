# MyLibrary - Online Library System

This is a simple online library system created using React and Vite.

## Technologies

- React
- Vite
- React Router
- Redux Toolkit
- Tailwind CSS

## Features

- Home page
- Book categories
- Popular books
- Browse books
- Search books by title or author
- Filter books by category
- Book details page
- Add new book
- Redux state management
- Form validation
- 404 page
